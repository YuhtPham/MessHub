Câu hỏi thường gặp

MessHub gom các phiên đăng nhập nhắn tin riêng vào một giao diện desktop, kèm workspace, tin nhắn mẫu, thông báo và tiện ích trên khay hệ thống.

Thiết lập workspace và tài khoản được lưu trên thiết bị. Tin nhắn được hiển thị bởi dịch vụ bạn đăng nhập; chính sách dữ liệu của nền tảng đó vẫn được áp dụng.

Node.js phiên bản LTS (20.x trở lên). Sau đó chạy npm install và npm start.

Chỉnh sửa src/renderer/styles/platform-overrides.css. Bạn có thể đổi màu nền, độ mờ kính (backdrop-filter), hoặc ẩn/hiện bất kỳ thành phần nào bằng CSS.

Có cấu hình đóng gói cho Windows, macOS và Linux. Xem các lệnh build trong package.json.
